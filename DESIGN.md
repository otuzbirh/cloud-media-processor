# Design system

## Direction

Cloud Media Processor uses a calm operations workspace. A conventional top app bar keeps navigation familiar while the processing screen prioritizes the upload, configuration, and execution path. Personality comes from precise typography, compact status treatment, and a restrained teal accent.

## Color

- Graphite `#18221F`: primary text and strong controls.
- Canvas `#F5F7F6`: low-glare workspace.
- Paper `#FFFFFF`: bounded working surfaces.
- Muted teal `#28695F`: primary actions, progress, and active processing state.
- Mint `#3DAA83`: connected and completed states.
- Red is reserved for failures and destructive actions.

## Typography

Use Outfit at weights 400, 500, 600, and 700. Display roles use compact tracking and strong scale jumps. Metrics use tabular numerals. Body copy stays below 75 characters where possible.

## Layout

Desktop uses a 72 px top app bar and a wide operational canvas. Processing opens with a compact task header and sequential pipeline state, then pairs the file workspace with a sticky white configuration panel. Mobile wraps the app bar into two rows and stacks actions in task order.

## Components

- Pipeline rail communicates real sequential state.
- Surfaces use either a border or elevation, never both.
- Metric ribbons share one bounded surface and use dividers instead of independent cards.
- Pills are reserved for statuses and deployment policy.
- Controls use 9–10 px radii; primary content surfaces use 14 px.

## Interaction

Route changes use one short clip-and-focus entrance. Direct actions use restrained color and position feedback. Reduced-motion preferences disable authored motion.

## Content

Use sentence case and Bosnian operational language. Buttons name the resulting action. Errors identify the problem and a recovery path when available.
